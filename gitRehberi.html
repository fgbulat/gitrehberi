İleri Python Ders 62: Git ve GitHub – RPA Projelerinde Versiyonlama

Seviye: 🟡 Orta | Tip: 🛠️ Pratik Uygulama

🤖 RPA Bağlantısı: RPA robotları geliştikçe, eski çalışan koda dönmek, süreç değişikliklerini takip etmek ve ekip halinde çalışmak zorlaşır. Git versiyon kontrol sistemi bu sorunları tamamen çözer.

🎯 Kazanımlar

  • Git nedir, neden kullanılır? (Versiyon kontrolünün temel mantığı)
  • Temel Git komutları (init, add, commit, push, pull)
  • Branch (dal) kavramı – Farklı robot senaryolarını yönetme
  • GitHub ile uzak depo (remote repository) kullanımı
  • .gitignore ile gereksiz ve hassas dosyaları dışlama
  • Bir RPA projesini GitHub üzerinde güvenle yayınlama

📖 1. Git Nedir? Neden Kullanırız?

Git, bir dağıtık versiyon kontrol sistemidir. Kod dosyanızdaki tüm tarihsel değişiklikleri anlık olarak kaydeder ve dilediğiniz zaman projenin geçmişteki kararlı bir sürümüne dönmenize olanak tanır.

📌 Analoji: Bir fatura aktarım robotu geliştiriyorsunuz. "Ders 10" aşamasında sorunsuz çalışıyordu; ancak yeni özellikler eklerken robot bozuldu. Git sayesinde kodunuzu tek bir komutla "Ders 10" anındaki çalışan haline döndürebilirsiniz.

⚙️ 2. Git Kurulumu ve Kimlik Yapılandırması

# Kurulum Sonrası Sürüm Kontrolü
git --version

# Küresel Kullanıcı Bilgilerinin Tanımlanması (İlk Kurulumda 1 Kez Yapılır)
git config --global user.name "Adınız Soyadınız"
git config --global user.email "eposta@ornek.com"

📁 3. Yerel Depo (Repository) Oluşturma

# Proje klasörüne geçiş yapın
cd rpa_projem

# Git deposunu başlatın (.git gizli klasörü oluşur)
git init

# Çalışma alanının durumunu kontrol edin
git status

# Tüm yeni/değişen dosyaları izlemeye alın
git add .

# Değişiklikleri versiyon olarak kaydedin (Commit)
git commit -m "İlk commit: RPA projesi altyapısı kuruldu"
📌 Commit Nedir? Değişikliklerin onaylanmış bir anlık görüntüsüdür (snapshot). Projenizin geliştirme sürecindeki kilometre taşlarıdır.

🔄 4. Günlük Çalışma Akışı ve Temel Komutlar

# Anlık durumu inceleyin
git status

# Belirli bir dosyayı veya klasörü staging alanına ekleyin
git add robot.py
git add moduller/

# İzlenen tüm değişiklikleri commit edin
git commit -m "PDF veri ayıklama modülü tamamlandı"

# Commit geçmişini tek satırlık özetler halinde listeleyin
git log --oneline

# Eski bir commit versiyonuna geçici olarak dönün
git checkout 

# Ana dala (main/master) geri dönün
git checkout main

🌿 5. Branch (Dal) Yönetimi

Branch yapısı, ana çalışan koda zarar vermeden yeni özellik denemeleri yapmanızı sağlar.

# Yeni dal oluşturma
git branch yeni_excel_robotu

# İlgili dala geçiş yapma
git checkout yeni_excel_robotu

# Dal oluşturup doğrudan geçiş yapma (Kısayol)
git checkout -b yeni_ozellik

# Mevcut dalları listeleme
git branch

# Çalışmanızı ana dal ile birleştirme
git checkout main
git merge yeni_excel_robotu

# İşlevi biten dalı silme
git branch -d yeni_excel_robotu
🎯 RPA Projelerinde Dal Mimarisi:
  • main: Canlıda (Production) sorunsuz çalışan robot kodu.
  • dev / gelistirme: Yeni modüllerin eklendiği test alanı.
  • hotfix: Acil giderilmesi gereken canlı hataları için ayrılan dal.

🐙 6. GitHub – Uzak Depo Kullanımı

Git lokal ortamınızda çalışırken; GitHub bu depoları bulut üzerinde yedeklemenizi ve ekip ortamında paylaşmanızı sağlar.

# 1. Yerel depoyu GitHub'daki uzak depoya bağlama
git remote add origin https://github.com/kullanici_adi/rpa_fatura_robotu.git

# 2. Yerel kodları GitHub'a gönderme (Push)
git push -u origin main

# 3. Uzak depodaki güncellemeleri yerel projeye çekme (Pull)
git pull origin main

# 4. Mevcut bir depoyu bilgisayara indirme (Clone)
git clone https://github.com/kullanici_adi/rpa_fatura_robotu.git

🚫 7. .gitignore – Hassas ve Gereksiz Dosyaları Dışlama

# .gitignore dosyası oluşturma ve kural ekleme
echo "__pycache__/" >> .gitignore
echo "*.log" >> .gitignore
echo ".env" >> .gitignore
echo "logs/" >> .gitignore
echo "temp_downloads/" >> .gitignore
📌 RPA Projelerinde Takibe Alınmaması Gereken Dosyalar:
  • __pycache__/ – Python derlenmiş bytecode dosyaları
  • *.log – Çalışma anında üretilen log kayıtları
  • .env – Parolalar, API anahtarları, özel bağlantı tümceleri
  • *.xlsx / *.pdf – Test sırasında işlenen geçici müşteri verileri

📋 8. Sık Kullanılan Git Komutları Özeti

Komut Açıklama
git init Yeni bir Git deposu başlatır.
git clone <url> Uzak depoyu yerel makineye kopyalar.
git add . Tüm değişiklikleri staging alanına alır.
git commit -m "mesaj" Değişiklikleri versiyon kaydı olarak işler.
git push Commit edilmiş değişiklikleri uzak depoya aktarır.
git pull Uzak depodaki son değişiklikleri yerel projeye indirir ve birleştirir.
git status Çalışma alanındaki dosyaların durumunu gösterir.
git log --oneline Geçmiş commit kayıtlarını özet olarak gösterir.
⚠️ Güvenlik Uyarısı: Veritabanı şifrelerini, SAP/Portal kullanıcı bilgilerini ve API anahtarlarını KESİNLİKLE GitHub depolarına commit etmeyiniz. Bu tür verileri .env dosyasında tutup .gitignore listesine ekleyiniz.

✍️ Uygulama Alıştırmaları

  • Yerel ortamınızda yeni bir RPA proje klasörü açıp git init ile depoyu başlatın.
  • Bir .gitignore dosyası oluşturup .env ve *.log uzantılarını dışlayın.
  • gelistirme adında bir dal oluşturup yeni bir Python fonksiyonu ekleyin ve main dalı ile birleştirin.

🏠 Mini Ödev

Senaryo: Hazırladığınız Otomatik Fatura İşleme Robotunu GitHub üzerinde yayınlayın.

  1. GitHub hesabınızda rpa_fatura_robotu adında kamuya açık/özel bir repo açın.
  2. Projeye anlaşılır bir README.md dosyası ekleyerek robotun ne iş yaptığını açıklayın.
  3. .gitignore dosyasını doğru yapılandırdığınızdan emin olun.
  4. İlk sürümünüzü main dalına push edin.
